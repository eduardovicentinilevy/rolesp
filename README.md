# Rolê SP

Guia de São Paulo para turistas brasileiros e estrangeiros: pontos turísticos, restaurantes, bares e botecos, padarias e cafés, sorveterias, baladas e, principalmente, **lugares bairristas**, aqueles que o paulistano frequenta e o turista normalmente não conhece.

> 🚧 Em construção. Fase atual: **1 — plano de arquitetura**.

- Arquitetura, modelo de dados e decisões técnicas: [`docs/arquitetura.md`](docs/arquitetura.md)

**Stack:** React (Vite) · Node.js + Express · PostgreSQL (SQL puro, sem ORM) · Leaflet + OpenStreetMap · react-i18next · Jest + Supertest · Docker Compose · Google Cloud Run + Cloud SQL + Firebase Hosting
